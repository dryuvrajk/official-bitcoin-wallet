## Overview

**Bitcoin Wallet** is a customised Android wallet application developed and distributed by **Decima Technologies India**.

The application provides users with a ready-to-use wallet environment configured for the Bitcoin Mainnet operated by Decima Technologies.

Unlike conventional wallet installations that may require users to manually configure network servers, this distribution comes with its designated Electrum server and block explorer preconfigured.

Our objective is straightforward: provide a consistent, accessible and streamlined wallet experience without requiring users to configure network infrastructure themselves.

## Key Features

| Feature | Description |
|:---|:---|
| **Ready-to-use configuration** | Network connectivity is preconfigured. |
| **Dedicated Electrum Server** | Connects exclusively to the designated Electrum endpoint. |
| **Official Block Explorer** | Uses the designated Mempool Explorer. |
| **Bitcoin Wallet Interface** | Familiar wallet experience based on the BlueWallet open-source project. |
| **Android Application** | Distributed as an installable Android APK. |
| **Dedicated Distribution** | Maintained and distributed by Decima Technologies India. |

## Network Configuration

The application is configured to communicate with the following network infrastructure.

| Component | Configuration |
|:---|:---|
| Network | Bitcoin Mainnet operated by Decima Technologies |
| Network Operator | Decima Technologies India |
| Electrum Server | `electrum.sovereignchain.in` |
| Electrum Port | `50001` |
| Protocol | TCP |
| Block Explorer | `mempool.sovereignchain.in` |
| Explorer Protocol | HTTPS |

### Block Explorer

All supported transaction and block explorer references use the designated explorer:

**https://mempool.sovereignchain.in**

Users can independently access the explorer to inspect supported transaction and block information.

## Installation Instructions

1. Open the latest release in this repository.
2. Download the Bitcoin Wallet APK.
3. Open the downloaded APK on your Android device.
4. If prompted, allow installation from the source used to download the APK.
5. Complete the installation.
6. Open Bitcoin Wallet.

The application comes with its designated network configuration already integrated.

**Note:** Android may display a security warning when installing applications outside Google Play. Only install APKs obtained from the official releases published in this repository.

## Important Network Disclosure

This application is configured for a separately configured Bitcoin mainnet operated by Decima Technologies.

This network is not connected to or operated by the existing decentralised Bitcoin network.

The network operates under a centrally administered block production model and does not rely on conventional Bitcoin mining.

The use of Bitcoin Core software as the underlying technology does not imply affiliation, endorsement or operational association with the existing public Bitcoin network or its developers.

Users should distinguish between the network operated by Decima Technologies and the existing decentralised Bitcoin network. 

Transactions cannot be sent from Sovereign Bitcoin Mainnet to the Decentralized Bitcoin Mainnet Network, though research is in progress.
